**تقدیم با عشق به توسعه‌دهندگان ایرانی ❤️**

یه افزونهٔ راست چین ساز برای اینکه استفاده از Cline در VS Code برای فارسی‌زبان‌ها راحت‌تر باشه.! 🌱

## راهنمای استفاده

### ویندوز 🪟

1. فایل ZIP پروژه رو از حالت فشرده خارج کن.
2. وارد پوشهٔ `windows` شو.
3. فایل `launcher.bat` رو اجرا کن.
4. از منو، گزینهٔ Install / repair RTL patch  رو انتخاب کن و مراحل رو دنبال کن.
5. بعد از اتمام کار، VS Code رو یک بار ببند و دوباره باز کن.

### لینوکس 🐧

1. فایل ZIP پروژه رو از حالت فشرده خارج کن.
2. ترمینال رو در پوشهٔ پروژه باز کن.
3. این دستورها رو اجرا کن:

   ```bash
   chmod +x linux/launcher.sh
   ./linux/launcher.sh
   ```

4. از منو، گزینهٔ Install / repair RTL patch  رو انتخاب کن و مراحل رو دنبال کن.
5. بعد از اتمام کار، VS Code رو یک بار ببند و دوباره باز کن.

### برگردوندن تغییرات

اگه خواستی به حالت قبل برگردی، راه‌انداز رو دوباره اجرا کن و گزینهٔ **Restore original CSS from backups** رو انتخاب کن.

# English

**Made with love for Iranian developers ❤️**

A small, easy-to-use helper for a more comfortable Cline experience in VS Code. Get it, run it, and enjoy! 🌱

## How to use

### Windows 🪟

1. Extract the ZIP archive.
2. Open the `windows` folder.
3. Run `launcher.bat`.
4. Choose the install or repair option and follow the prompts.
5. Restart VS Code when it finishes.

### Linux 🐧

1. Extract the ZIP archive.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   chmod +x linux/launcher.sh
   ./linux/launcher.sh
   ```

4. Choose the install or repair option and follow the prompts.
5. Restart VS Code when it finishes.

### Restore the previous version

Run the launcher again and choose **Restore original CSS from backups**.
